# Bureo

Factures et pro forma, agenda, notes et rappels, mails et coffre à mots de passe :
tout le bureau d'un indépendant ou d'une PME dans une seule application Windows.

## Télécharger

👉 **[Télécharger la dernière version de Bureo](https://github.com/rarianaAina/bureo-releases/releases/latest)**
(fichier `Bureo-Setup-….exe` dans la liste « Assets »).

- Windows 10 ou 11, aucun droit administrateur nécessaire.
- 14 jours d'essai complets, sans inscription.
- Les mises à jour s'installent ensuite toutes seules.

Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur
**Informations complémentaires**, puis **Exécuter quand même**.

## Acheter une licence

Contactez l'éditeur de Bureo : vous recevez une clé à coller dans
**⚙️ Réglages > Licence**. Vos données restent sur votre ordinateur.
